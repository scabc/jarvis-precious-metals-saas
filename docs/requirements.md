# 产品需求文档 (PRD) - MVP 版本

## 1. 网页前端功能
- **基础登录**: 简单的用户认证。
- **订阅管理**: 用户选择不同的订阅等级或开启/关闭服务。
- **监控配置**:
  - 选择监控种类 (金、银、铂、钯等)。
  - 选择参考来源 (如各交易银行价格)。
- **UI 风格**: 极简主义，重点在于功能而非视觉复杂性。

## 2. 后端逻辑
- 匹配前端配置，按需抓取和处理数据。
- **银行价格抓取**: 需要针对主流银行的贵金属牌价页面编写爬虫。

## 3. 核心：信息发送渠道 (Notification)
- **邮件发送 (Priority 1)**: 实现自动化邮件预警推送。
- **扩展性**: 预留其他接口位置，但首期暂不实施。
